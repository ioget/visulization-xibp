# XamCoach coaching intelligence workspace

## Goal
Build a polished, light-only sports intelligence product for French women’s basketball coaching staffs. The interface will make verified data, AI interpretation, evidence, and next actions immediately distinguishable.

## Product foundation
- Establish the XamCoach visual system in semantic tokens: specified slate surfaces, orange actions, blue data, status colors, compact Inter typography, restrained radii, borders, shadows, and motion.
- Build one responsive application shell with a 240px workflow-based sidebar, compact page header, AI readiness indicator, notifications, coach profile, and collapsible tablet navigation.
- Create reusable primitives for metrics, data tables, chart frames, comparison bars, AI labels, expandable source evidence, statuses, selectors, reports, empty/loading/error states, export actions, shot charts, and tactical boards.
- Keep all mock content in typed data structures so live services can replace it later without redesigning the interface.

## Screens
- **Home:** greeting, compact quick actions, team snapshot, upcoming matchup, recent activity, and a restrained AI intelligence brief.
- **Ask Coach:** suggested prompts, evidence-aware AI response layout, key verified numbers, visible sources, and an inline animated tactical half-court.
- **Player Analysis:** professional player profile, season KPIs, trend chart, percentile comparison, shot chart and zone efficiency, creation profile.
- **Team Analysis:** sortable roster intelligence table and immediately readable team-versus-league comparisons.
- **Scouting:** report setup state and generated development report state with statistics, shot profile, AI-labelled SWOT, evidence, development plan, and export controls.
- **Pre-Match:** matchup identity, form and key-player comparison, followed by concise AI tactical briefing and evidence.
- **Post-Match:** final score, game-flow chart, verified performers, AI-labelled interpretation, and next coaching actions.
- **Practice Planner:** focused configuration flow and generated 90-minute timeline with review/export actions.
- **Knowledge Graph:** basketball-specific relationship map with search, entity filters, zoom controls, legend, and node detail panel.
- **System Monitor:** compact operational status, latency, uptime, health check, and activity log.
- **Settings:** vertically separated profile, AI provider, notification, and light appearance sections.

## Interaction and resilience
- Wire navigation and screen-level actions across real application routes.
- Add source expansion, report generation state transition, tactical play/replay, table sorting, graph selection/filtering, planner selection, and mobile sidebar behavior.
- Include representative skeleton, actionable empty, AI analyzing, and coach-friendly error states within the reusable system.
- Keep AI content mocked and visibly labelled; no backend, authentication, or real AI calls will be added in this frontend phase.

## Verification
- Check desktop and tablet layouts at the requested breakpoints, including navigation collapse, stacked layouts, scrolling tables, readable charts, and non-overlapping content.
- Verify the main interactions in the live preview and confirm each content route has unique page metadata.
